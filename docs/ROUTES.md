# Frontend routes & navigation

Every route of the web app (`frontend/src/App.tsx`) and what it shows. The Lab app routes by the same web
paths (`android-lab/app/…/ui/nav`).

### Frontend Routes
- Navigation: a bottom **tab bar** (`components/nav/TabBar`, rendered by `Header`) — tutor account (users.role): Students · Chats · Decks · Library · More; student: Study · Chats · ＋ Add · Progress · More (`LEARNER_TABS` — the Tutor tab went in Nov 2026, Jerome: "a dud page"; `/connections` lights More; its slot became ✦ Claude, then (Nov 2026, "I don't really use this page") **＋ Add** → `/add`, docs/ADD_TAB.md; the old Claude tab's box — with its suggestion chips — is the Chats tab's box, docs/CHAT.md "The Claude tab → ＋ Add"); account with students: Students · Chats · Study · More (+ Progress if they also study). The Chats tab carries an unread badge (conversations with unread messages); Decks is the first row of More (a `/decks` page lights More up — for a tutor account its own Decks tab). Hidden on immersive routes (`/study`, quest play, readers, editors, chat — `isImmersiveRoute`). `html.has-tab-bar` pads the document so nothing sits under it.
- `/` - Study home (a tutor account gets the teaching home, `TutorHome`). On the app's initial entry it applies `users.landing_page` (Settings → "Start on"; `PUT /api/profile/landing-page`, exposed on `/api/auth/me`), else the automatic rule: Students when the account has an active student and nothing due today, otherwise Study (`components/nav/landing.ts`).
- `/add` - The learner's ＋ Add tab (docs/ADD_TAB.md; `pages/AddPage.tsx`, Lab `ui/add/`): "Add a word" — 📷 a photo (one tap to the camera → `POST /api/ocr/words`, Lab ML Kit on the phone first → the Chinese lines as word chips, the big central line first → the explorer → + Add as card / ⚡ Study it today; ✂ Pick a span), ✏️ type / 🎤 say it in Chinese or English (`POST /api/ai/english-words`; nothing records until 🎤 / 🗣 is tapped — opening or coming back to the tab never starts a take) — and "Ask for new content" tiles (reader, mini lesson, audio lesson, clips, picture hunt, deck, just ask Claude) with "✓ Making your reader… Open ›"
- `/claude` - The old ✦ Claude tab: redirects to `/chats?compose=1` (the Chats tab's Claude box; Lab `ClaudeTabRedirect`)
- `/chats/claude/:id` (`new` + `?context=card&note_id=` / `?text=&intent=`), `/chats/claude/:id/recap` - One Claude thread, any context (immersive; docs/CHAT.md "Claude thread view"); `/coach/chat/:id` redirects here
- `/chats` (`?compose=1` = the box ready to type, `?text=` = with that text, `?practice=1` = the "🎭 Practice a situation" sheet) - The unified Chats tab (docs/CHAT.md "Chats tab — one list for people and Claude"; compact since Nov 2026): the people first (a learner's unread tutor chats on top), a thin full-width divider, then the Claude threads (`mergeInbox` + `inboxSections`, `shared/claude/inbox.ts`) — ONE-line rows (~60px: avatar, name, time, unread; no previews, no outlines, no kind labels — the sections + avatars carry the kind, never colour), a Claude row's ONE context emoji (📇 / 📖 / 🧩 / 🎭 / ✏️ …) → a popover with the full text + "Open card / story / lesson ›", search (no filter chips), ✏️ new chat (✦ Claude, 🎭 Practice a situation… — a role-play thread, docs/CHAT.md "Practice with Claude" —, or a person); the box at the bottom (`components/chats/ChatsComposer.tsx`, Claude.ai style, voice-first) always goes to Claude — idle ✏️ Type · 🎤 Say it, Ask (Enter), and ✏️ Check · 🔍 Explain for Chinese / 🔤 Translate for English only once there is text → a new thread, opened (offline: queued). A tutor account / an account with students: the same layout (no pinning), a box with Ask · Translate. Cached offline, live while open (`pages/ChatsPage.tsx`, `hooks/useChatList.ts`, `hooks/useClaudeInbox.ts`)
- `/decks` - Deck list (grouped in folders when there are any) + card search (`?q=`; `/search` redirects here) — More → Decks, Home "All decks →"
- `/more` - Grouped More page (Decks first, then Practice / From your tutor / Teaching / Account / Advanced) — replaces the avatar dropdown
- `/profile` - Profile (`pages/ProfilePage.tsx`, `components/profile/`): display name, photo (crop sheet → 512px JPEG → R2 `avatars/<user>/<id>.jpg`, served by the public `GET /api/audio/<key>`), About me (public: `PersonAbout` on the tutor / student page, the /join page), time zone (the other side sees your local time), and the learner's private bio. **`users.name` / `picture_url` stay the effective values every query reads** (migration 0076 adds `google_name`, `google_picture_url`, `name_custom`, `picture_source`, `picture_key`, `about`, `time_zone`); the Google sign-in (`touchExistingUser` → `googleProfileRefresh`, and the MCP server's OAuth callback) always refreshes the `google_*` columns but only overwrites name / picture while the user follows Google. Reached from More (user card + Account → Profile), Settings, and the tutor's Students dashboard header chip / "Introduce yourself" nudge
- `/settings` - Profile link · Offline audio (one line; audio downloads itself after every sync) · Backup · Start on · Feedback (Send feedback, "Shake to send feedback") · Sign out · Advanced (audio quality, playback quality, conversation voices (`/settings/voices`), sentence coverage, feature requests, duplicate finder, full sync, update app, debug)
- `/connections` - Students dashboard for tutors with students (cards, pending invites, homework decks); otherwise **Tutors & connections** (More → From your tutor; pending requests + Accept / Decline, sent requests, invites, My Tutors — the legacy Claude practice partner hidden; `?invite=1` opens connect-by-email). A request waiting on a learner shows on Home (`components/home/ConnectionRequestsBanner.tsx`, `connectionRequestsLine`)
- **The chat is the way in to the person** (`shared/chats/personLinks.ts`, Lab core `ChatPersonLinks.kt`, parity-tested): the chat header's avatar + name open `/connections/:relId` (`components/chat/ChatPersonLinks.tsx`), the chat ⋯ menu lists `chatPersonLinks` — a learner: 👤 About <tutor> · 📝 Lesson board · 📚 Homework from <tutor> (`#homework`) · 🚩 Cards you flagged (`#flags`) · 🗒 Notes from <tutor>; a tutor: <student>'s page · Lesson board (Lab: `?section=homework|flags`). Analytics `chat.person_link`, `chat.connection_requests_open`
- `/connections/:relId` - Student page (tutor: status, Message / Send homework, needs attention, homework, conversations, activity; new student: setup checklist) / tutor page (student — opened from the chat header / Tutors & connections, ‹ Back returns there; `#homework` / `#flags` sections)
- `/connections/:relId/chat/:convId` - Chat interface (a merged-away id swaps to the pair's one chat); `/connections/:relId/chat` opens THE chat with that person
- `/connections/:relId/progress` - Student progress view (tutor only)
- `/library`, `/library/:id`, `/library/:id/edit`, `/library/:id/print` - Tutor lesson library, item (assignments + push update), editor, print view
- `/lessons/:id/edit`, `/lessons/:id/print` - Lesson editor / print view for a student's own lesson or one the tutor assigned
- `/lessons/:id/play?from=lessons_page|homework|today` - ▶ Start / ▶ Do it again outside the session (immersive; Practice only when not due)
- `/library/catalogue`, `/library/catalogue/:sampleId` - Exercise catalogue / a sample lesson as a trial (immersive, nothing recorded)
- `/connections/:relId/lesson-attempts[/:attemptId]`, `/lesson-attempts[/:attemptId]` - Lesson attempt review (tutor / learner)
- `/readers/:id/edit`, `/readers/:id/print` - Reader editor (form + preview + Claude co-editor + exports) / print view
- `/readers/:id/recap` - 📝 Reader word recap of the story's latest reading (immersive, offline; docs/STUDY_SESSION.md "Reader word recap")
- `/connections/:relId/insights` - Student Insights: range, needs attention / going well, summary, lesson log (tutor only)
- `/connections/:relId/history` - Full review history explorer with filters (tutor only)
- `/connections/:relId/recordings` - Recordings inbox with listened / needs-work marks (tutor only)
- `/connections/:relId/cards/:noteId`, `/connections/:relId/claude-chats`, `/connections/:relId/claude/:threadId` - Tutor's view of one of the student's cards (hub) / the chats with Claude the student lets her read / one of them, read-only (immersive)
- `/cards/:noteId`, `/claude-chats` - The student's own card hub / Claude conversations (More → Claude conversations)
- `/connections/:relId/homework/:jobId` - Review a homework draft made from lesson notes (tutor): load gauge, words / skipped, modes, split, Claude chat, Assign
- `/homework`, `/homework/:id` - The student's one-off homework (to do / done) and the pass (immersive)
- `/cards/held` - "Suspended & snoozed cards" (Settings → Study, More → Decks): search, All / Suspended / Snoozed, Unsuspend / Wake now per row and in bulk, Undo — offline (`pages/HeldCardsPage.tsx`, Lab `ui/cardcontrols/HeldCardsScreen.kt`)
- `/up-next`, `/connections/:relId/up-next` - "Up next" (docs/STUDY_SESSION.md "Up next"): ⚡ Today + search (＋ Top / ＋ Bottom / press-and-hold a result and drag it into place) + the ordered list (drag, ↑, ⚡, ✕ with Undo) — offline-first (`services/upNext.ts`, IndexedDB `upNext` / `upNextOps`); the tutor's view of a student's list (online). More → Up next, Home's "↑ N up next" line, "↑" on deck rows / the card hub
- `/tutor-notes`, `/tutor-notes/practice?cards=&notes=` - Notes from your tutor (More → From your tutor, Home row) / practising those cards in the study card (immersive; a rating counts only when due)
- `/audio-lessons`, `/audio-lessons/:id` - Audio lessons: list + New audio lesson (Dialogue / Sleep / Story; More → Practice), the player (immersive; offline once opened)
- `/podcasts`, `/podcasts/feed?url=`, `/podcasts/episodes/:id` - 🎙 Podcasts — **Lab app only** (no web page yet; docs/PODCASTS.md)
- `/watch`, `/watch/:id`, `/watch/share?text=&url=` - 📺 Watch (追剧, docs/WATCH.md; More → Practice, tutors More → Tools): my videos + paste a YouTube link + Find on YouTube, the player (immersive: YouTube's embed, the line card, ⏮ 🔁 ⏭, speed, Pause after each line, Listen first, the transcript), and the installed app's share target (manifest `share_target`)
- `/idioms`, `/idioms/:hanzi` - 成语 Idioms (beta): look one up / browse the starter list, and one idiom's page (More → Practice; tutors More → Tools; the explorer's "📜 Story & usage")
- `/clips`, `/clips/:id[?scene=N]` - 🎬 Clips (experimental; More → Practice "🎬 Clips (beta)"): the vertical feed (immersive, its own chrome; /clips/:id starts at that clip, `?scene=` at a scene)
- `/phone`, `/phone/:id` - 📱 Phone practice (More → Practice, tutors More → Tools): the task list (✓ Done · best time, local only) and one task on the simulated phone (immersive; full screen on a phone, a phone frame + task card on a desktop)
- `/meme-review`, `/meme-review/:month` - 梗 Meme review (prototype; More → Practice, tutors More → Tools): the monthly issues (admin: Generate now) and one issue (offline once opened; links need a connection)
- `/picture-hunt`, `/picture-hunt/:id` - Picture hunt: list + make / upload, and the game (immersive; More → Practice)
- `/coach/chat/:id` - "💬 Ask Claude" from the Coach: redirects to the Claude thread view `/chats/claude/:id` (both apps)
- `/practice/strokes?text=` - Handwriting with stroke-order feedback (preview; More → Practice, and study card ⋯ → Write it). Stroke data = hanzi-writer-data (Arphic PL) copied to `/strokes/<hex>.json` at build by `strokeDataPlugin` (vite.config.ts), cached per character in its own IndexedDB (`services/strokeData.ts`); `components/strokes/WritingExercise.tsx` is the drop-in exercise. See docs/STROKE_ORDER.md
- `/materials`, `/materials/:id` - Lesson materials (not in any menu since Oct 2026; the call's Present material sheet uploads too): upload / share / rename / delete, and the page viewer (cache-first, offline)
- `/calls`, `/calls/:id`, `/calls/:id/review` - Video calls (beta): list + start (More → Video calls, or 📹 on a student / tutor page), the live call (immersive), transcript + lesson report + flashcards
- `/admin/audio` - Admin: TTS providers (status per provider, enable, max RPM, voices with ▶ samples, stored / live order, upgrade backup clips, backlog + Retry / Run backfill; docs/AUDIO.md "Providers")
- `/vr` - 🥽 VR (beta, docs/VR.md): a WebXR room (Enter VR in a WebXR browser — on the Steam Frame the community Chromium XR —, else a flat 3D preview): grabbable Study / Reader / Homework / Explorer / mini-lesson / Feedback windows, 🎤 speech into the focused window, 💬 feedback with a screenshot (`POST /api/feedback`). Immersive, lazy, not in the tab bar (More → Practice, Settings → Advanced). Web only by design
- `/vr/worlds`, `/vr/worlds/:id[?vr=1]` - 🌏 VR worlds (beta, docs/VR_WORLDS.md): the picker (cards with progress; More → Practice, 🌏 Worlds on the /vr tray) and one world (immersive, lazy: physics, tasks in Chinese, inspect → word → + Add as card into "From VR"; `?vr=1` asks to Enter VR at once)
- `/connections/:relId/board` - The Lesson board: every page of the video-call board with that person, read-only, offline ("📝 Lesson board · N pages" on the student / tutor page)
