# Hard mode: one Stop bar, no bars above the ratings, a calmer study card

Phone shots are 412×915 at 2×. The Lab app shots use the dark theme, plus one light shot. The web app only has a light theme, so its shots are light. Wide shots are 841px (the Fold's inner screen). The card sentence is 你闻闻这个牛奶是不是坏了。.

## Lab app (dark)

**Question side.** The frame sits at the screen's edge, with a thin border and a small radius.

![Lab question, before](lab-01-question-before.png) ![Lab question, after](lab-01-question-after.png)

**Sentence round while recording.** There is ONE pinned "■ Stop recording"; the round's own footer is held. The exercises have no boxes: a hairline separates them, and the numbered mark shows each one's state (✓ green, red while recording).

![Lab round recording, before](lab-02-round-recording-before.png) ![Lab round recording, after](lab-02-round-recording-after.png)

**Answer side, top.** The answer has no green outline around the card, and there is no "✓ 2/2 right — Good and Easy unlocked" banner. The fun fact is plain text, and the footer row is lighter.

![Lab answer top, before](lab-03-answer-top-before.png) ![Lab answer top, after](lab-03-answer-top-after.png)

**Answer side, the sentences.** Each row spans the full width, with ▶ at the end of the first line. EN, 🎤 and the tools sit on one quiet line under the sentence. "In the round · ✓ Right" and "From the card" are small inline marks, not boxes or tabs.

![Lab answer sentences, before](lab-04-answer-sentences-before.png) ![Lab answer sentences, after](lab-04-answer-sentences-after.png)

**After 👁 Show answer.** The "You looked at the answer" bar is gone. Hard is ringed, and Good and Easy are greyed with "tap twice". The reason is still there as the buttons' TalkBack text.
